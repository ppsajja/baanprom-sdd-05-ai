| ไฟล์ | คืออะไร | มาจากบทเรียน |
|---|---|---|
| catalogue.md | ข้อความต้นฉบับของ REQ ทุกข้อที่ UC-07, UC-08, UC-09 แตะ (3 ข้อที่ใช้ทุก feature ย้ายข้อความไปไว้ที่ specs/000-shared/constraints.md ตาม CR-04 REQ ของ UC-08 และ UC-09 เพิ่มตาม CR-05, CR-06) | Requirements Catalogue |
| UC-07.md | use case fully dressed ของ UC-07 | Use Case และ Acceptance Criteria |
| UC-08.md, UC-09.md | use case fully dressed ของ UC-08 และ UC-09 (AI ร่างตอน /clarify ทีมตรวจ เข้า B2 ตาม CR-06, CR-05) | รอบ R1 release |
| glossary.md | คำที่ใช้ได้ และชื่อในโค้ด | Living Specification |
| baseline.md | Baseline B2 (ด้านบน รวมการปรับปรุง 18 ต.ค. 2569 = ขอบเขต R1) บันทึกเดิมของ B1 กติกาเปลี่ยนแปลง และตาราง CR | Living Specification และ Verification, Traceability และ Change |
| operations.md | คู่มือรับมือเหตุ (runbook) รุ่นร่าง 3 เหตุการณ์ตาม REQ-OP-006 และแบบบันทึกเหตุการณ์ (AI ร่างแทนทีม รอ Ops lead เป็นเจ้าของ ที่มา CR-07 Proposed) | รอบ Failure Day (ข้อกำหนดด้านปฏิบัติการและความน่าเชื่อถือ) |
