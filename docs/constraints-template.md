กติกาของไฟล์นี้
- ทุกข้อในไฟล์นี้ใช้กับ**ทุก feature** โดยไม่ต้องคัดลอกไปไว้ใน spec.md ของ feature
- spec.md ส่วน 8 ของทุก feature มีบรรทัดอ้างบรรทัดเดียว: "Constraint กลาง: ใช้ทุกข้อใน specs/000-shared/constraints.md รุ่น x.y"
- feature ไหนทำตามข้อใดไม่ได้ ต้องเขียนข้อยกเว้นพร้อมเหตุผลและผู้อนุมัติไว้ในส่วน 8 ของ spec นั้น
- ข้อความเต็มของทุกข้ออยู่ที่นี่ที่เดียว (docs/srs/catalogue.md เหลือแค่รหัสและชี้มาที่นี่)
- แก้ไฟล์นี้ต้องเปิด CR และดูตารางข้อ 3 ว่ากระทบ feature ไหน AI ห้ามแก้ไฟล์นี้เอง (AGENTS.md กฎข้อ 9)

| ตัวอย่าง REQ-PRV-002 | เบอร์โทรลูกค้าเป็นข้อมูลส่วนบุคคล ห้ามบันทึกลง log ของระบบ | PDPA | ทุกโมดูลขอ logger ผ่านไฟล์เดียวที่กรองเบอร์ และ feature ที่แตะเบอร์โทรมี test ตรวจว่า log ไม่มีเบอร์ |

## 2. การตัดสินใจทางเทคนิคของทีม
