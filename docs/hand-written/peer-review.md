## คำถาม "ถ้าเกิดข้อยกเว้นนี้ ระบบทำอะไร"

ถาม: ถ้า Payment Gateway ไม่ตอบ ระบบทำอะไร
ตอบจาก spec ได้: สอบถามสถานะด้วย reference เดิม ถ้าได้ unknown งานเป็น "ยกเลิกอัตโนมัติ" และช่วงเวลากลับเป็น "ว่าง" (REQ-IF-005, AC-07-05, MD-SEQ-07-05)

ถาม: ถ้าลูกค้าคนอื่นจองช่วงเวลาเดียวกันไปก่อน ระบบทำอะไร
