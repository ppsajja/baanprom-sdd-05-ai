## การตัดสินใจทางเทคนิค

P-01 ล็อกช่วงเวลาด้วย state ใน TimeSlot และหมดอายุอัตโนมัติ
- รองรับ: REQ-FN-041, MD-STM-01 | ค่าอายุ = Q-18 (config)
- ปฏิเสธ: ตรวจซ้ำตอนชำระเท่านั้น (E2 เกิดบ่อย, D-07-01)

P-02 การชำระเป็น authorize-then-capture
- รองรับ: REQ-IF-001, MD-SEQ-07-05 (void ก่อนแจ้ง E2)
- ปฏิเสธ: capture ทันที (คืนเงินยาก, ขัด BR-01 R5)

P-03 status-inquiry แบบ idempotent ด้วย ref เดิม
- รองรับ: REQ-IF-005 | timeout = Q-19 (config)
- ปฏิเสธ: ส่ง authorize ใหม่เมื่อ gateway เงียบ (เสี่ยงตัดเงินซ้ำ)

P-04 แจ้งเตือนผ่าน queue และ retry
- รองรับ: REQ-FN-012 (60 วินาที), IF-02
- ปฏิเสธ: เรียก SMS แบบ sync ใน request (ขัด REQ-QA-003)
